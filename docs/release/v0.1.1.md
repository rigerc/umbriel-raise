# Release Notes: v0.1.1

## Public Notes

- Reliably rotate through every matching window using Umbriel's focus history.
- Move the cursor to a raised window so focus remains reliable for runtime
  switcher keybindings.
- Preserve spaces, quotes, empty values, and shell metacharacters in launch
  arguments.
- Retain activation-token launches and stale-window retry behavior.

## Internal Notes

- Window selection now uses seat-global `active` state instead of
  workspace-local `focused` state.
- Cycling treats Umbriel's window list as most-recently-focused order and
  rotates to the least-recent match when the application is already active.
- Spawn argv is POSIX-shell-quoted before it crosses Umbriel's `/bin/sh -c`
  boundary.

## Security Or Privacy Notes

Shell metacharacters supplied as application arguments are now treated as
literal data instead of being interpreted as additional shell syntax. No data
collection or privacy behavior changed.
