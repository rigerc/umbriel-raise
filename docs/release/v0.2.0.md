# Release Notes: v0.2.0

## Public Notes

- Add `umbriel-raise setup`, a guided terminal wizard for finding exact Umbriel
  app IDs and creating raise-or-launch keybinds.
- Discover running applications automatically, or refresh and enter an app ID
  manually when the application is not open.
- Validate generated keybinds before displaying or saving them, without editing
  the active Umbriel configuration.
- Generate actions with the absolute `umbriel-raise` executable path so
  keybinds continue to work when the compositor has a restricted `PATH`.
- Add accessible and no-color prompts plus safe optional file output with
  explicit overwrite protection.

## Internal Notes

- Add Huh v2 for the interactive terminal form while keeping discovery,
  generation, validation, and output boundaries independently testable.
- Group `umbriel windows --json` results by exact app ID and sanitize terminal
  control and direction-format characters before display.
- Validate generated table keybinds through `umbriel validate -c` using a
  temporary config file.
- Preserve the existing `--app-id APP_ID -- COMMAND` activation interface and
  behavior unchanged.

## Security Or Privacy Notes

The wizard performs no network requests, telemetry, clipboard access, active
config mutation, or automatic application launches. Optional output refuses to
overwrite an existing file unless `--force` is explicit.

## Verification Source

`docs/srs/srs-walkthrough.md` records focused TDD evidence, an accessible CLI
end-to-end test, race/vet/build/gopls checks, and live validation against the
installed Umbriel 0.1.0 compositor.
